# 劳动补偿计算器（Labor Compensation Calculator）

离职能拿什么（**N / N+1 / 2N / 无**）、未休年假折算、加班费——按法定标准逐项算给你看，每一项都附法条出处。

单文件网页 · 零依赖 · 完全离线 · **你填写的数据不上传**

---

## 快速开始

- **在线用**：打开在线版：<https://everstoneai.github.io/labor-compensation-calculator/> ，点开即用。
- **本地用**：下载 `index.html`，双击用浏览器（Chrome / Edge 等现代版本）打开。无需安装、无后端、不联网。

使用流程：选「怎么离开的」（12 种情形）→ 填入职/离职日期与工资 → 按需展开年假、加班费模块 → 点「开始计算」→ 结果逐项给金额＋法条出处。

## 它算什么

1. **情形分支（12 种）**：协商解除、主动辞职、被迫辞职、无过错辞退（提前 30 日与否 → N 或 N+1）、经济性裁员、到期不续、破产解散、任务完成终止、违法解除（2N，与 N 择一）、到龄退休（无）等，结论逐项附法条出处；
2. **N 的计算**：年限按日历周年精确到日折算（满 6 个月按 1 年、不满 6 个月按半个月）× 应得工资基数（前 12 个月均值或逐月填）；低于当地最低工资自动兜底；超当地社平 3 倍自动封顶（3 倍基数 + 12 年上限）；
3. **未休年假折算**：累计工龄三档（含前单位），未休天数 × 日工资（÷21.75）× 300% 口径（额外 200%），本人书面放弃则额外为 0，离职当年按日历折算参考；
4. **加班费**：平时 150% / 休息日未补休 200% / 法定节假日 300%，基数自填；
5. **常见误区澄清**（"被裁都有 N+1""2N 和 N 能一起要"等 5 条）与 **v1 边界说明**常驻页面。

## 它不做什么（边界）

- 只计算**法定标准**，不构成法律意见；协议金额、仲裁与判决的实际结果可能不同；
- 不判「该不该仲裁、能不能赢」，不预测任何结果；
- v1 不覆盖：2008-01-01 前入职的分段计算（自动警示建议咨询）、医疗期/工伤特殊保护期、劳务派遣等特殊用工、各地裁量差异（2N 年限封顶存在实务争议，页面按主流口径实现并标注）。

## 隐私与安全

- 所有计算在你本机浏览器完成，数据**不上传、不联网、无统计埋点**；
- 代码就 `index.html` 一个文件，无构建、无依赖，全部逻辑可直接审阅。
